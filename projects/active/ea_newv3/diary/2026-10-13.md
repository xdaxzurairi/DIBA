### Bug & teknik ditemui (worth remembering)
- Write tool tulis content **verbatim**, bukan JSON-decode — `\\'` (double backslash) sebelum apostrophe Inggeris jadi 2 aksara literal, patahkan string JS. Guna `\'` sahaja. Sahkan dgn `node --check` (extract `<script>` ke fail berasingan, bukan `node -e` inline).
- Verify PDF lengkap tanpa poppler (`pdftoppm` tak installed): grep teks biasa gagal (Chrome subset font + Identity-H encoding), screenshot headless gagal (PDF viewer tak render dlm mod screenshot). Kaedah berjaya: baca `/Kids` di bawah `/Type /Pages` (kira muka surat), banding saiz stream `/Contents` tiap halaman.
- `chrome.exe --headless --print-to-pdf` perlukan path **format Windows** (`C:/...`) dalam Git Bash — `$(pwd)` bagi path POSIX `/tmp/...` yang Chrome tak faham.
