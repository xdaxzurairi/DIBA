## 2026-08-04 (Afternoon - 16:45) - EA New v3: Split-screen Login, Bug Seksyen Ralat, MinIO Integration

### Session summary
Sesi panjang meliputi 4 kerja dalam projek eAduan v3 (EA New v3): redesign login jadi split-screen korporat, fix bug dropdown SEKSYEN yang papar "Ralat" sebelum dipilih, dan implementation penuh integrasi MinIO object storage untuk foto aduan (dari design doc sehingga test sambungan dev sebenar lulus).

### Key decisions
- Login page ditukar dari centered-card kepada split-screen 50/50 CSS Grid — Abam confirm "bagus clean"
- Root cause bug Seksyen: `ajax/get_seksyen.php` ada corrupted `/m<?php` di baris 1, bukan logik JS — dibetulkan
- MinIO: guna custom `MinioClient` (AWS SigV4 manual, `hash_hmac`+`curl`) berbanding vendor library S3.php pihak ketiga yang tak diaudit
- Object key MinIO guna prefix `ea_newv3/` untuk elak collision dengan modul FMS lain yang kongsi bucket `907-fms`/`fms`
- Atas arahan Abam, path key dipendekkan: buang lapisan `wr/` — terus `ea_newv3/{no_aduan}/foto{n}.ext` (bukan `ea_newv3/wr/{id}/...`)
- Fallback wajib: MinIO down semasa upload → simpan local `uploads/wr/` macam asal, jangan block submission borang
- Test CLI terhadap MinIO dev sebenar (putObject + presigned GET + simulasi imej JPEG) — LULUS penuh; ini turut sahkan reachability endpoint terus (bukan VPN-only), jadi pendekatan redirect 302 dalam `ajax/foto.php` kekal (tak perlu proxy-stream)
- Isu `curl.cainfo` php.ini tempatan menunjuk fail tak wujud — dibetulkan dalam kod (`applyCaBundle()` fallback), bukan ubah `php.ini` server yang dikongsi
