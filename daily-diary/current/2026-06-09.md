### Bug Fix: Respond Time & Action Time Salah Kira

User mengadu respond time dan action time ada salah kira dalam sistem eWorks.

**Siasatan mendapati 2 bugs:**

**Bug 1 — `calculateResponsePeriod()` dalam `api/approve_complaint.php`**
- `strtotime($responseDateTime)` gagal apabila `$responseDateTime` adalah `DateTime` object dari MSSQL PDO driver
- PHP tidak boleh cast DateTime object ke string untuk strtotime
- Akibat: `response_period` dan `response_period_m` selalu 0 atau salah
- Fix: Guna `$SYSDATE_responded` (string 'Y-m-d H:i:s' yang dah diformat) untuk strtotime
- Commit: `cc6f639` (dibuat pagi tadi 11:28)

**Bug 2 — `action_period` tidak disimpan ke DB dalam `kemaskini.php`**
- Commit `a9738e3` (11:30 pagi) ada tambah PHP calculation untuk `$action_period`
- Tapi nilai tidak dimasukkan dalam SQL UPDATE statement dan params array
- Akibat: `action_period` sentiasa NULL/0 walaupun PHP dah kira
- Fix: Tambah `action_period = CASE WHEN ? IN ('Com','clo') THEN ? ELSE action_period END` dalam SQL + 2 params
- Commit: `6bf02fb` (2:26 ptg — commit hari ini yang lengkapkan bug ini)
