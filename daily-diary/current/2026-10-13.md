**Jana PDF sebenar** — headless Chrome:
```
chrome.exe --headless --disable-gpu --no-sandbox \
  --print-to-pdf="docs/UAT-ea_newv3.pdf" --print-to-pdf-no-header \
  --virtual-time-budget=8000 "file:///C:/.../uat-ea-newv3.html"
```
Nota: path *mesti* format Windows (`C:/...`), bukan `$(pwd)` dalam Git Bash (bagi path POSIX `/tmp/...` yang `chrome.exe` tak faham → `ERR_FILE_NOT_FOUND`).

**Sahkan PDF lengkap tanpa poppler** (`pdftoppm`/`pdftotext` tak installed pada mesin ni): cuba grep teks biasa dalam PDF dulu — gagal (false negative), sebab Chrome subset font + Identity-H encoding, teks literal *tiada* dalam bait mentah walaupun render betul. Cuba screenshot headless Chrome terus ke fail PDF — gagal juga (placeholder kosong, PDF viewer tak render dalam mod screenshot headless). Kaedah yang *berjaya*: parse struktur PDF terus — baca `/Kids [...]` di bawah objek `/Type /Pages` (8 muka surat), banding saiz stream `/Contents` setiap objek muka surat (muka surat lewat, tempat 60 kes berada, ada stream *lebih besar* daripada muka surat depan — konsisten dengan kandungan sebenar ada, bukan terpotong).
