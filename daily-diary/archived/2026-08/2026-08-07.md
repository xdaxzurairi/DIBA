## 2026-08-07 (Afternoon - 12:18) - eWorks: Paparkan Foto Aduan dari ea_newv3 pada kelulusan_aduan.php

### Session summary
Abam minta foto kerosakan yang diambil semasa pengguna buat aduan di ea_newv3 (kolum `foto1/foto2/foto3` pada jadual `wr`, storan MinIO atau lokal legacy) dipaparkan pada `kelulusan_aduan.php` (eWorks) semasa proses kelulusan aduan. Disahkan kedua-dua aplikasi berkongsi DB SQL Server yang sama (`10.0.36.97 / FMSDEV`) dan folder `eWorks`/`ea_newv3` adalah sibling di bawah `webs/`, jadi helper MinIO ea_newv3 boleh direquire terus dari eWorks tanpa duplicate credential.

### Key decisions
- Tidak proxy melalui `ea_newv3/ajax/foto.php` sedia ada kerana ia bergantung pada session `sso_authenticated` ea_newv3 — tak wujud dalam konteks login eWorks. Sebaliknya require terus `ea_newv3/includes/minio.php` (path relatif `__DIR__ . '/../ea_newv3/includes/minio.php'`) dari dalam `kelulusan_aduan.php`.
- Logik pembezaan storan: jika nilai kolum foto ada `/` → key MinIO baru → jana presigned URL (`minioPresignedUrl($key, 3600)`); jika tiada `/` → nama fail lokal legacy → link terus ke `../ea_newv3/uploads/wr/{filename}` (folder ini sudah web-accessible untuk imej ikut `.htaccess` sedia ada).
- Fail selamat (graceful): jika `.env` MinIO ea_newv3 tiada/rosak, `minioPresignedUrl()` pulang `null` dan foto itu diabaikan sahaja — tiada crash pada borang kelulusan.

### Fail yang diubah
- `//10.0.36.127/webs/eWorks/kelulusan_aduan.php` — Tambah `require_once` untuk `ea_newv3/includes/minio.php`; tambah query `SELECT foto1, foto2, foto3 FROM wr WHERE wr_id=...` dan logik bina URL (`$foto_urls`); tambah baris "Foto Kerosakan" dalam seksyen BUTIRAN KEROSAKAN yang papar thumbnail boleh diklik (buka saiz penuh tab baru) atau teks "Tiada foto dilampirkan".

### Follow-ups
- Belum diuji secara visual di browser (tiada akses browser dalam sesi ini) — perlu Abam sahkan render sebenar untuk aduan yang ada foto (kedua-dua kes: MinIO key dan fail lokal legacy).
- Task eworks kedua yang disebut di awal sesi ("dual task antara ea_newv3 dan eworks") belum dijelaskan — tunggu arahan lanjut Abam.
