## 2026-08-13 - pwa_eworks: Fix Paparan Mobile & Gambar Kerosakan Tak Papar dalam Modal Detail

### Session summary
Susulan fitur upload gambar kerosakan (siap 2026-08-11), Abam laporkan dua bug melalui screenshot: (1) UI upload gambar pada `form_aduan_inisiatif.php` versi mobile "tidak kemas" — butang Kamera/Galeri overflow/terpotong; (2) gambar kerosakan yang sedia ada di server tidak papar langsung dalam paparan "maklumat terperinci"/modal BUTIRAN PELAPOR. Kedua-dua bug disahkan dan dibaiki dalam sesi ini; Abam sahkan "dah papar" selepas fix kedua.

### Bug 1 — Layout mobile pecah (foto_upload_ui.php)
- **Punca 1:** inline `style="grid-template-columns: 200px 1fr;"` pada `.form-group` override rule responsive `@media (max-width:768px)` dalam `form.css` (inline style menang atas class walaupun class ada `@media`). Fix: buang inline style, biar CSS class asal handle mobile stack.
- **Punca 2:** butang Kamera/Galeri dalam flexbox row (`display:flex;gap`) overflow sebab teks butang lebih panjang daripada ruang flex-basis pada skrin sempit. Fix: tukar kepada `flex-direction:column` (susun menegak), `width:100%`, + `white-space:nowrap;overflow:hidden;text-overflow:ellipsis` sebagai safeguard.
- Juga tukar `#foto-preview-row` grid dari `repeat(3,1fr)` ke `repeat(3,minmax(0,1fr))` supaya thumbnail preview tak overflow.

### Bug 2 — Gambar kerosakan tak papar dalam modal detail
- **Diagnosis penting:** pwa_eworks ada BEBERAPA paparan detail aduan yang berasingan (tiada shared include) — `paparan_lengkap_aduan.php`/`paparan_lengkap_print_body.php` (dah ada seksyen foto dari sesi 08-11), `complaints.php` (modal JS BUTIRAN PELAPOR), dan `index.php` (modal serupa tapi berasingan). Setiap satu kena diupdate berasingan.
- Sempat salah diagnosis awal — andaian "belum ada aduan yang guna flow upload baru" (0 rekod dengan prefix MinIO `pwa_eworks/`). Screenshot susulan Abam (No. Aduan 1295585, ada foto1/foto2 dari era ea_newv3) buktikan punca sebenar ialah modal `complaints.php` memang tiada langsung kod papar gambar — bukan isu data/simpan.
- **Fix di `complaints.php`:** tambah seksyen "GAMBAR KEROSAKAN" dalam modal detail (`modalFotoSection`/`modalFotoGrid`), guna data `foto1/2/3` yang sedia ada dalam `window.complaintsData` (sumber `SELECT w.*` dalam `getComplaints()`) — papar `<img>` via `api/foto.php?wr_id=...&idx=N`. Ini modal yang padan tepat dengan screenshot Abam (footer "Tutup"/"Tindakan").
- **Fix di `index.php`:** seksyen sama ditambah pada fungsi `showComplaintModal(complaintId, complaintData)`. **Nota:** grep menyeluruh sahkan fungsi ini sebenarnya tidak dipanggil dari mana-mana UI (dead code/tidak reachable buat masa ini) — fix ditambah untuk berjaga-jaga, tidak menjejaskan apa-apa, tapi bukan punca bug yang dilapor.
- Butang "Tindakan" (`openQuickAction`/`statusActionModal`) dalam `complaints.php` disahkan modal BERBEZA (untuk update status), sengaja tidak ditambah seksyen foto.
