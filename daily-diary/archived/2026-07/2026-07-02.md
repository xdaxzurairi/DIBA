## 10:41 — Fix cetak_arahan_kerja.php & cetak_arahan_kerja_b.php

**Task:** Jenis Peralatan terpapar salah dalam borang arahan kerja print

**Masalah yang dilaporkan:**
- `cetak_arahan_kerja.php` dan `cetak_arahan_kerja_b.php` memaparkan "Flush type switch socket outlet-13 Amp, retangular pin()" secara default untuk SEMUA aduan — termasuk BANGUNAN (bumbung bocor, plumbing) yang tidak ada kaitan dengan peralatan tersebut
- User minta paparan sama seperti `cetak.php`

**Root cause:**
- `cetak.php` ada reset `if ($eq_id == '') { $eq_id = "-"; }` sebelum query equipment
- Bila `eq_id` kosong (""), query `WHERE e.eq_id=''` ambil rekod default dalam table `eq` → terpapar "Flush type switch socket outlet"
- `cetak_arahan_kerja.php` dan `cetak_arahan_kerja_b.php` **tiada** reset ini → query ambil rekod default

**Fix:**
- Tambah `if ($eq_id == '') { $eq_id = "-"; }` menggunakan `replace_all: true` di semua occurrences `$parse_eq=` dalam kedua-dua fail (D5033 block + else block = 2 tempat setiap fail)
- Buang kondisi `if (!empty($peralatan))` yang pernah ditambah (menyebabkan baris hilang terus)

**Fail diubah:**
- `\\10.0.36.150\webs\eWorks\cetak_arahan_kerja.php` — tambah reset eq_id (2 lokasi)
- `\\10.0.36.150\webs\eWorks\cetak_arahan_kerja_b.php` — tambah reset eq_id (2 lokasi)

**Status:** Selesai ✓ — user konfirm "ok dah betul"

**Perangkap yang dijumpai:**
- Edit tool gagal kerana ada tab whitespace tersembunyi dalam fail — guna `replace_all: true` dengan pattern yang lebih ringkas untuk bypass
- Jangan tambah `if (!empty($peralatan))` — cetak.php tunjuk baris kosong, bukan sorok terus
- Punca masalah bukan di cetak.php tapi di fail cetak_arahan_kerja yang tiada reset
