## 2026-07-08 (14:30) - ScoutOps Full System Upgrade — 10 Tasks Selesai

### Session summary
Sesi penuh implementasi pelan sistem besar ScoutOps menggunakan Subagent-Driven Development. Kesemua 10 task berjaya diselesaikan merangkumi 6 fasa: Auth DB, CSRF & Rate Limiting, Bright Theme, Flatpickr + app.js, Role Badge, Per-evaluator Evaluation System, Stats Pages, Dashboard Stats + Chart.js, CSV Export/Import/PDF, dan Admin Panel. Commit akhir d3f7931 — 31 fail diubah, 2,978 baris ditambah.

### Key decisions
- Gunakan Subagent-Driven Development (fresh implementer → spec reviewer → code quality reviewer per task)
- Auth session key = `scoutops_user_id` (INT user ID), timeout 8 jam
- Warna tema terang: primary `#1D6FE8` (sky blue) + accent `#F59E0B` (amber), sidebar kekal gelap `#1D3A6E`
- Per-evaluator scoring: setiap evaluator ada rekod `evaluations` sendiri, skor composite dikira semula bila submit
- Weighted average: head_coach 60% / asst_coach 40% (boleh toggle dalam admin settings)
- Composite formula: offense×0.25 + defense×0.20 + athleticism×0.15 + mental×0.15 + position×0.15 + future×0.10
- `$ROOT = '../'` untuk subfolder admin/ dan import/ (bukan `../../` — Apache alias map /scoutops → public/)
- CSRF via `bin2hex(random_bytes(32))` + `hash_equals()`, simpan dalam `$_SESSION['csrf_token']`
- Rate limiting: 5 gagal dalam 10 minit per IP+username via jadual `login_attempts`
- Open redirect protection: `str_starts_with(rawurldecode($redirect), APP_BASE . '/')`
- `unset($row['password_hash'])` sebelum cache user dalam session — isu keselamatan ditemui semasa code review
