## 2026-07-10 (Petang - 17:30) - ScoutOps: Kawalan Akses sheet_sync.php + Vercel Deploy

### Session summary
Abam minta had akses halaman `sheet_sync.php` (Sync from Google Sheet) berdasarkan role — Admin nampak semua 3 bahagian, Head Coach dan Asst Coach nampak bahagian 1 dan 2 sahaja. Ditemui bug dalam panggilan fungsi `auth_require_role` yang menyebabkan hanya admin boleh akses. Fix dibuat dan deploy ke dua project Vercel (baseball & scoutops-navy).

### Key decisions
- `auth_require_role` perlu guna syntax array `['admin','head_coach','asst_coach']` — bukan argument berasingan (PHP hanya ambil argument pertama)
- Bahagian 3 (Automatic scheduled sync) kekal untuk admin sahaja via `is_admin()` — tidak perlu ubah
- Dua project Vercel berasingan: `baseballfederationmalaysia.vercel.app` dan `scoutops-navy.vercel.app`
- scoutops-navy masih 403 selepas deploy — disyaki role "ed" berbeza dalam DB scoutops-navy

### Fail yang diubah
- `public/import/sheet_sync.php` — Tukar `auth_require_role('admin', 'head_coach')` → `auth_require_role(['admin', 'head_coach', 'asst_coach'])` untuk beri akses Asst Coach ke bahagian 1 & 2

### Follow-ups
- Semak role user "ed" dalam DB scoutops-navy (kemungkinan ada role berbeza atau user tidak wujud)
- scoutops-navy masih 403 — perlu verify via Admin → Users atau query DB terus

## 2026-07-10 (Malam - 21:00) - ScoutOps: DB Permission Fix + UI English Translation

### Session summary
Selepas context compaction, ditemui error baru: `SQLSTATE[42501]: permission denied for table evaluator_roles`. Root cause: migration SQL tidak include GRANT kepada user `scoutops_app` yang digunakan oleh PHP app. Fix dibuat via Supabase MCP dengan grant terus kepada user tersebut. Sesi ini juga menterjemah semua teks UI dalam `evaluator_roles.php` dari Bahasa Melayu ke Bahasa Inggeris atas permintaan Abam.

### Key decisions
- `scoutops_app` adalah PostgreSQL user yang digunakan PHP app (bukan `postgres`, `anon`, atau `authenticated`)
- GRANT kepada `postgres/authenticated/anon/service_role` tidak mencukupi — perlu grant terus kepada `scoutops_app`
- Migration SQL masa depan perlu include: `GRANT ALL ON TABLE scoutops.<table> TO scoutops_app;`
- Semua teks UI sistem ditukar ke Bahasa Inggeris (flash messages, labels, buttons, headings)
- Respons DIBA ditukar ke Bahasa Inggeris atas permintaan Abam

### Fail yang diubah
- `public/admin/evaluator_roles.php` — Terjemah semua teks UI ke English (flash messages, table headers, buttons, form labels, hints)
- Supabase DB (via MCP) — `GRANT ALL ON scoutops.evaluator_roles TO scoutops_app` + sequence grant

### Follow-ups
- Pastikan migration SQL masa depan sentiasa include GRANT kepada `scoutops_app`
- Semak jika ada teks Melayu lain dalam fail PHP lain yang terlepas pandang
