## 2026-05-25 (Tengahari - 13:30) - PWA eWorks: DB Schema Audit & Archibius Migration Prep

### Session summary
Audit penuh semua tables yang diperlukan oleh sistem PWA eWorks. Ditemui 9 tables baru perlu dicipta dalam FMSPROD/FMSDEV dan 5 column baru perlu ditambah dalam table `wr` sedia ada. Semua auto-create dalam PHP dibuang — table creation dipindah sepenuhnya ke Archibius melalui SQL script. Dokumen HTML dan export Excel/Word disediakan untuk admin Archibius.

### Key decisions
- **Buang semua auto-create** dari 7 fail PHP: `rate_limiter.php`, `get_notifications.php`, `device_manager.php`, `forgot-password.php`, `reset-password.php`, `track_pwa_install.php`, `send_pending_notifications.php`
- **9 tables baru** untuk FMSPROD: `login_attempts`, `rate_limit_events`, `push_subscriptions`, `user_notifications`, `app_devices`, `password_reset_tokens`, `push_notification_log`, `app_installations`, `wr_status_history`
- `wr_status_history` adalah **KRITIKAL** — tanpanya kemaskini status aduan akan crash (INSERT dalam transaction tanpa try-catch)
- `BIT` datatype tidak disokong Archibius → ditukar ke `SMALLINT`
- `TEXT` deprecated → ditukar ke `NVARCHAR(MAX)` untuk `app_devices.user_agent`
- UNIQUE constraint pada `NVARCHAR(2048)` endpoint dibuang — melebihi had index key SQL Server 1700 bytes; dedupe dihandle di PHP
- **5 column ALTER TABLE wr**: `flag_notify`, `flag_app`, `flag_email`, `device_id`, `status_date`
- Script SQL ada IF NOT EXISTS guard — selamat run berulang kali tanpa drop

### Fail yang diubah

- `scripts/pwa_tables_schema.html` — dokumentasi schema dalam HTML
- `scripts/pwa_tables_export.php` — export ke Excel (`?format=excel`) atau Word (`?format=word`)
- `scripts/check_dev_db.php` — schema viewer untuk FMSDEV (baru)
- `includes/rate_limiter.php` — buang auto-create `login_attempts` dan `rate_limit_events`
- `api/get_notifications.php` — buang auto-create `user_notifications`
