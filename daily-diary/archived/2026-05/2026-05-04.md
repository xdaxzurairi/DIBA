## 2026-05-04 (Petang) - pwa_emajlis: PWA Installable + Modul Permohonan & Kelulusan

### Session summary
Sambungan pembangunan `pwa_emajlis` — sistem pengurusan majlis PWA untuk UiTM. Sesi ini memfokuskan kepada 3 perkara: (1) pastikan PWA boleh install pada mobile, (2) bina Modul Permohonan, (3) bina Modul Kelulusan Permohonan.

### Key decisions
- Icon PWA guna `emajlis.png` (logo rasmi e-Majlis dengan kubah + 3 orang + buku) — resize ke 192px dan 512px
- Manifest icons dipisah kepada 4 entry (`any` + `maskable` × 2 saiz) — ikut spec PWA
- iOS meta tags ditambah: `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style`, `apple-mobile-web-app-title`
- SW cache version bump ke `v1.1.0` — tambah `calendar.js` dan versioned CSS
- `permohonan.php` role-based: group=0 nampak permohonan sendiri, group≥1 nampak semua
- `mohon.php` guna step-form 3 langkah (Maklumat Asas → Lokasi & Sesi → Semak & Hantar)
- `kelulusan.php` admin-only — default filter status=1 (menunggu kelulusan)
- Sidebar JS di-extract ke `includes/sidebar_js.php` — reusable semua pages
- `mj_permohonan.trkh_tukar_status` dikemaskini apabila status berubah

- `sw.js` — cache v1.1.0, tambah calendar.js + icon-512
- `assets/img/icon-192.png` + `icon-512.png` — jana dari emajlis.png
- `includes/head.php` + `login.php` + `index.php` — iOS meta tags, CSS v3
- `includes/sidebar.php` — link kelulusan.php, permohonan.php
- `includes/sidebar_js.php` — **BARU** extract sidebar JS
- `permohonan.php` — **BARU** senarai permohonan (dual view)
- `mohon.php` — **BARU** step form permohonan baru
