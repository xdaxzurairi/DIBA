## 2026-04-24 (Petang - 17:30) - eRuangNiaga Security Cleanup & Bug Fixes

### Session summary
Sesi penuh security cleanup dan bug fixing untuk projek eRuangNiaga. Audit menyeluruh mendedahkan banyak isu tertinggal — credentials hardcoded, debug output aktif, form CSRF rosak, dan tab login tidak perlu. Semua diselesaikan dalam satu sesi dengan 5 commit.

### Key decisions
- Alih UiTM SSO credentials (client_id, client_secret) ke .env — selaras dengan DB credentials yang dah dipindah commit sebelum
- Buang tab "ID & Password" dari modal login staf — tinggalkan SSO UiTM + Google sahaja
- Mass fix 42 fail: artefak `\n` literal + trailing `"` dari commit CSRF lama (882d409) — guna byte manipulation langsung sebab regex Python gagal interpret `\n` dalam bytes pattern
- signup_konvo.php perlu include csrf_helper.php secara berasingan (tidak include session.php)

### Fail yang diubah
- `verify.php` — Alih SSO credentials ke .env, buang print_r/echo debug, fix error exposure, buang undefined var + stray ?>
- `.env` — Tambah UITM_SSO_CLIENT_ID + UITM_SSO_CLIENT_SECRET
- `.env.example` — Tambah template keys SSO
- `admin/cabutan_keputusan.php` — Buang 2 baris console.log DEBUG
- `login.php` — Buang tab ID & Password, modal alternatif, JS functions, console.log debug (173 baris dihapus)
- `signup_konvo.php` + 41 fail lain — Fix `\n` literal → CRLF sebenar, buang trailing `"` selepas csrf_input()
- `signup_konvo.php` — Tambah `include_once 'includes/csrf_helper.php'` (borang kosong sebab function undefined)
