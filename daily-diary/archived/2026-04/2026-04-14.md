## 2026-04-14 (Petang) - UI Fixes: Filter, Pagination, Header & Cetak

### Session summary
Sesi penuh bug fix dan UI improvement pada complaints.php, kemaskini.php, paparan_lengkap_aduan.php dan functions.php. Isu utama yang diselesaikan: pagination membuang status filter kerana variable `$status` ditimpa dalam loop complaint, elemen/jenis kerosakan tidak papar disebabkan query salah guna `prob_group.section`, dan header Kemaskini/Kelulusan Aduan tidak ikut logic yang betul.

### Key decisions
- Default senarai aduan: R (Permohonan) + I (Arahan Kerja Dikeluarkan) + WC (Salah Saluran) sahaja
- Header kemaskini.php: `I/I2/WC/I3` = "Kemaskini Aduan", semua lain = "Kelulusan Aduan"
- ICT dibuang dari seksyen, elemen dan jenis kerosakan
- Paparan cetak mobile: kekal format A4, scale ikut viewport, button Kembali → kemaskini
- `$cStatus` digunakan dalam loop (bukan `$status`) untuk elak overwrite filter variable

### Fail yang diubah

- `kemaskini.php` — Fix header logic (Kemaskini/Kelulusan); fix button Kembali guna `$_GET['back']` dengan fallback session
- `paparan_lengkap_aduan.php` — Button Kembali → kemaskini.php; button Cetak/Simpan PDF; layout A4 scale untuk mobile
- `includes/functions.php` — Fix `getUserProbGroupsForFilter()` guna `prob_group.section` column terus (bukan JOIN salah); buang ICT dari `getSections()`, `getUserSectionsForFilter()`, `getProbGroups()`, `getUserProbGroupsForFilter()`; tambah `restrict_main_statuses` dalam data + count query dalam `getComplaints()`
