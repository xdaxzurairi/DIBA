## 2026-04-17 (Pagi) - Feature: Reset Kata Laluan via Emel

### Session summary
Sesi ini membina ciri reset kata laluan sendiri untuk pengguna eWorks. Sebelum ini pengguna perlu hubungi admin untuk reset — kini sistem hantar pautan reset ke emel mereka secara automatik. Turut dibetulkan isu paparan kad tidak ditengah disebabkan `<body>` tag tanpa class.

### Key decisions
- Pilih Pilihan B (hantar reset link via emel) berbanding Pilihan A (verify terus)
- Guna raw SMTP socket (tanpa PHPMailer) kerana `proc_open` disabled di server — Composer tidak boleh install pakej baru
- SMTP credentials biarkan kosong — guna anonymous relay untuk penggunaan dalaman UiTM sahaja
- Token sah 1 jam; token lama dibatalkan bila user minta reset baru
- Fix paparan: tambah `<body class="login-page-body">` secara eksplisit kerana `head.php` tidak buka tag `<body>`

### Fail yang diubah
- `forgot-password.php` — Ganti logik "hubungi admin" kepada: verify akaun → jana token → hantar reset email; tambah `<body class="login-page-body">`; fix centering CSS
- `reset-password.php` (BARU) — Halaman set password baru via token; validate token (expired/used/invalid); hash bcrypt → kemaskini `afm_users.user_pwd`
- `includes/mailer.php` (BARU) — Raw SMTP client: socket → STARTTLS → AUTH LOGIN (skip jika credentials kosong) → hantar HTML + plaintext multipart email

### Follow-ups
- Test penghantaran emel sebenar (perlu verify SMTP relay server UiTM benarkan anonymous)
- Jika SMTP relay gagal, Abam perlu isi `SMTP_USERNAME` dan `SMTP_PASSWORD` dalam `config/config.php`
- Table `password_reset_tokens` auto-create pada request pertama (tiada migration manual diperlukan)
