## 2026-04-27 (Petang - 17:00) - eRuangNiaga Security Audit Full Remediation

### Session summary
Sesi penuh security remediation untuk eRuangNiaga berdasarkan audit report yang dikemukakan Abam. Semua isu critical dan high diselesaikan dalam satu sesi panjang — CSRF pada POST handlers tertinggal, SQL injection, hardcoded credentials, dead files, DB error exposure, N+1 session queries, dan Google login bug.

### Key decisions
- CSRF verify pattern: guna `csrf_validate()` untuk form POST, inline JSON check untuk AJAX endpoint
- Penyewa session.php perlu include `csrf_helper.php` secara berasingan (tidak melalui session.php admin)
- SQL injection fix: bind semua parameter guna named params PDO; integer cast untuk dynamic WHERE clause
- Google credentials, UITM SSO, dan JWT Bank API token — semua dialihkan ke `.env`
- DB error exposure: mass replace 108 fail — `$_SESSION['error'] = $e->getMessage()` → `error_log + generic message`
- Google login bug: `getenv()` tidak baca `$_ENV` (custom loader) — fix guna `$_ENV['KEY'] ?? getenv('KEY')`
- session.php N+1: tukar 11 blok `if` berasingan kepada satu loop + single DB query
