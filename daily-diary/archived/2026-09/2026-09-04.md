## 2026-09-04 (Petang) - Fix e-sign Senarai Aduan, Tarikh Siap, Gambar Kerosakan & Git Hook

### Session summary
Tiga permintaan berturut dari Abam untuk pwa_eworks + satu pembaikan git hook.

1. **Paparan status e-sign di Senarai Aduan** (aduan status `I` "Arahan Kerja Dikeluarkan") — cermin logik semakan fail e-sign dari skrin Tutup Arahan Kerja ke `complaints.php`, untuk paparan Kad DAN Jadual. Wording ditambah baik: "e-sign lengkap" / "e-sign belum lengkap (pengadu/kontraktor)" senaraikan pihak yang belum sign. Commit `05952c7` (sesi sebelum).
2. **Tarikh siap salah di Kelulusan Aduan** (`kemaskini.php`) — punca: guna `date_stat_chg`/`time_stat_chg` (masa tukar status terakhir), sepatutnya `date_completed`/`time_completed` (sama seperti Borang Arahan Kerja). Bukti: aduan 1295584 papar 16:26 sedangkan Borang AK papar 14:24. Fix dengan fallback. Commit `08209b4`.
3. **Gambar kerosakan tak papar untuk aduan status Siap** — punca: BUKAN bug status/kod. Hanya 1 rekod rosak: wr 1295584 (`test`, dari ea_newv3) ada `foto1 = 'ea_newv3/wr/1295584/foto1.jpg'` — key salah format (segmen `wr/` tambahan; konvensyen sebenar ea_newv3 = `ea_newv3/{wr_id}/foto1.jpg`). Probe MinIO: kedua-dua key (asal & dibetulkan) → `NoSuchKey`. Fail foto memang tak pernah naik ke MinIO. Foto ea_newv3 lain (wr 1295585) & foto pwa_eworks berfungsi normal.
4. **Ralat git hook** — setiap `git commit` lempar `Cannot find module '.../XDIBAX/diba-hub/cli/git-hook.js'`. Direktori `diba-hub` dah tiada di sistem.

### Key decisions
- Request #3: pilih **kosongkan rujukan tergantung** — `UPDATE wr SET foto1 = NULL WHERE wr_id = 1295584` (1 baris). Imej pecah hilang, seksyen GAMBAR KEROSAKAN tersembunyi. Dipilih sebab rekod `test` & objek MinIO memang tak wujud (tiada fallback kod boleh pulih).
- Tiada perubahan kod `api/foto.php` — hanya 1 baris rosak di seluruh table, tak berbaloi tambah fallback `/wr/` stripping.
- Git hook: kekalkan hook, tambah guard `[ -f "$HOOK_SCRIPT" ]` supaya no-op senyap bila diba-hub tak dipasang (bukan padam terus — kalau diba-hub dipulih nanti, sambung berfungsi).

### Fail yang diubah
- `kemaskini.php` (baris ~1716-1726) — guna `date_completed`/`time_completed`, fallback ke `date_stat_chg`/`time_stat_chg`. Commit `08209b4`.
- `complaints.php` — badge e-sign Kad + Jadual. Commit `05952c7` (sesi sebelum).
- DB: `wr.foto1` untuk wr_id 1295584 → NULL (data fix, tiada migration).
- `.git/hooks/post-commit` — tambah semakan `-f` sebelum panggil node. (Fail dalam `.git/`, tidak di-version-control.)

### Follow-ups
- Security audit pagi masih outstanding: tukar kata laluan `afm`@`FMSPROD`, keputusan git history purge, jana semula VAPID key.
- Jika ea_newv3 hasilkan lagi key `ea_newv3/wr/...` (bukan `ea_newv3/{id}/...`) pada masa depan, baru pertimbang fallback dalam `api/foto.php`.

### Open loops
