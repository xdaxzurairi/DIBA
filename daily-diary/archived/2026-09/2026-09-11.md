## 2026-09-11 (Petang) - CR eWorks: Test & Fix Bug Laporan 6f vs 4d

### Session summary
Sambung open loop pagi tadi: test laporan 6f (`lap_actiontime_all_kampus_tahap.php`) berbanding 4d (`lap_tahap_kerosakan.php`) untuk sahkan angka padan 100% seperti keperluan CR. Bina skrip PHP CLI standalone untuk banding logik query, kemudian jalankan fail PRODUKSI SEBENAR terus (bukan replika) untuk pengesahan muktamad — jumpa dan baiki satu bug SQL sebenar semasa proses.

### Key decisions
- Guna PHP CLI (`C:\php\php.exe`) + ADODB terus ke DB FMSDEV (host `10.0.36.97`) untuk test tanpa perlu browser/login — lebih pantas dan boleh automate banding.
- Test dengan 4 kampus (B01 Shah Alam, A01 Seri Iskandar, S01 Kota Kinabalu, J01 Segamat) dan julat tarikh besar (2015-2026) supaya sampel data bermakna (data bulan semasa/2026 kosong, tak berguna untuk validasi).
- Selepas skrip replika sahkan logik betul (padan 100% semua 4 kampus), langkah tambahan penting: `include` fail produksi SEBENAR dan tangkap `$ringkasan` terus (bukan just re-implement logik) — teknik ini yang berjaya detect bug sebenar yang replika saya sendiri tak ada.

### Bug dijumpai & dibaiki
- **Bug:** `lap_actiontime_all_kampus_tahap.php` baris 118-119, `$SQLotherfiler` guna `type_req`/`prob_type` TANPA alias jadual (`a.`). Disebabkan query 6f ada `LEFT JOIN probtype b` (yang turut ada lajur `prob_type`), MSSQL bagi ralat "Ambiguous column name 'prob_type'" — ADODB gagal senyap (tiada fatal error dipaparkan), jadi `$aggBySite` kosong dan SEMUA nilai jadi 0 bila fail dijalankan sebenar, walaupun logik pengiraan itu sendiri betul.
- **Fix:** Tambah alias `a.` → `and a.type_req != '5' and a.prob_type != 'PREVENTIVE MAINT'`.
- **Pengesahan selepas fix:** Jalankan semula fail produksi sebenar — `$ringkasan` untuk kesemua 4 kampus padan 100% (SIAP/TERTANGGUH/SIAPCAPAI/Jumlah Pelanggan/Jumlah Siap/MTLK/peratusan) dengan hasil query 4d yang dijalankan berasingan.

### Fail yang diubah
- `\\10.0.36.127\webs\eWorks\lap_actiontime_all_kampus_tahap.php` — Fix bug ambiguous column (baris 118-119, tambah alias `a.`).

### Follow-ups
