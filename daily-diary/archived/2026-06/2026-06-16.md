## 2026-06-16 (Malam) - pwa_eworks: Fix Dropdown Aras Kemaskini

### Session summary
Fix bug dropdown aras (fl_id) tidak populate dalam kemaskini.php. Punca: `api/get_floors.php` guna `INNER JOIN rm` dengan `SELECT DISTINCT` yang menyebabkan SQL error pada MSSQL (`ORDER BY items must appear in the select list if SELECT DISTINCT`). Juga semak aduan 1420009 untuk verify data.

### Key decisions
- Buang `INNER JOIN rm` dan `SELECT DISTINCT` dari `api/get_floors.php` — query terus dari jadual `fl` sahaja
- Ini fix betul kerana kita hanya perlu senarai aras untuk blok tertentu, bukan aras yang ada ruang

### Punca masalah (root cause)
1. `SELECT DISTINCT` + `ORDER BY f.name` — MSSQL reject sebab `ORDER BY` column mesti dalam `SELECT` list bila guna `DISTINCT`
2. `INNER JOIN rm ON f.fl_id = r.fl_id` — JOIN condition tak lengkap (tiada `bl_id` match), dan menyekat aras tanpa ruang daripada muncul

### Fail yang diubah
- `api/get_floors.php` — buang INNER JOIN rm, query fl terus dengan WHERE bl_id

### Verification
- Query baru return 14 aras untuk blok B0132A (termasuk 05 - ARAS LIMA)
- Query lama confirmed SQL error 42000
