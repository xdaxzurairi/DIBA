## 2026-06-05 (Pagi - 08:40) - BFM Auto-Sync SQLite: Endpoint + Frontend Hook

### Session summary
Tambah mekanisme auto-sync granular ke SQLite untuk projek Baseball Federation Malaysia. Sebelum ini `persist()` hanya sync ke `app_state` (JSON blob). Kini setiap CRUD (create/update/delete) akan upsert ke individual tables dalam satu transaction.

### Key decisions
- Tambah `/api/sync` POST endpoint — upsert ke semua 8 tables (clubs, players, officials, tournaments, matches, registrations, payments, club_applications) dalam satu BEGIN/COMMIT transaction
- Tukar `pushSnapshot()` di frontend dari `/api/data/snapshot` ke `/api/sync`
- GET `/api/data/snapshot` kekal untuk hydration on-load (baca dari `app_state` blob)
- POST `/api/sync` juga update `app_state` blob — kedua-dua path konsisten
- Debounce 450ms kekal — tidak perlu ubah kerana setiap keystroke tidak perlu langsung sync

### Fail yang diubah
- `server/index.js` — tambah `/api/sync` endpoint (BEGIN TRANSACTION, upsert 8 tables, COMMIT/ROLLBACK)
- `app/data.js` — tukar `pushSnapshot()` URL dari `/api/data/snapshot` ke `/api/sync`

### Follow-ups
- Tiada — mekanisme sync lengkap dan berfungsi
