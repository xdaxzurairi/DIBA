## 2026-06-30 (Awal Pagi) - Nemotron Agent (ReAct Loop) — Agentic Mode

### Session summary
Nemotron dinaik taraf dari sekadar chat kepada agentic mode penuh. Script `nemotron-agent.js` implement ReAct loop — Nemotron boleh READ, READ_RANGE, LIST, RUN, WRITE fail dalam workspace dan hasilkan laporan setiap task. Test berjaya: Nemotron baca server.js dalam 3 chunks dan senaraikan API endpoints tanpa crash.

### Key decisions
- ReAct pattern dipilih (bukan tool calling) — reliable untuk semua model
- READ terhad 80 baris, READ_RANGE untuk sambung baca fail besar
- Security: WRITE hanya dalam C:/Users/BSM/, RUN whitelist (node/git/npm sahaja)
- Retry 3x on ECONNRESET (OpenRouter network drop)
- Laporan auto ke `logs/nemotron-tasks/YYYY-MM-DD-HH-mm.md` termasuk direct response
- System prompt strict: NO JSON, format plain text sahaja
- PowerShell command `nemotron-agent` ditambah ke kedua-dua profile (pwsh + Windows PS)

### Fail yang dicipta/diubah
- `scripts/nemotron-agent.js` — ReAct loop engine (READ, READ_RANGE, LIST, RUN, WRITE, DONE)
- `logs/nemotron-tasks/` — folder laporan dicipta
- `Documents/PowerShell/Microsoft.PowerShell_profile.ps1` — tambah nemotron-agent
- `Documents/WindowsPowerShell/Microsoft.PowerShell_profile.ps1` — tambah nemotron-agent
