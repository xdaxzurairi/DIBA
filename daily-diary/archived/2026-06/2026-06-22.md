### Session summary
Abam minta tambah game simulation layer dalam War Room supaya DIBA dan NPC skills berkembang sebagai living entities. Implement penuh 9 sistem game — card stats, factions, quests, economy, challenges, self-improvement, mentor system, dan town buildings. Juga tambah 3 kapal terbang voxel blocky terbang pusing langit. Sungai dirancang tapi Abam minta buang.

### Key decisions
- Card stats (ATK/DEF/SPD/INT) dikira dari data sebenar: role base stats + usage count + growth level + agent active state
- Card rarity (Common → Mythic) berdasarkan growth + usage threshold
- 7 factions: Memory Cluster, Execution Chain, Forge Network, Session Bootstrap, Persona Control, Creative Guild, Project Ops
- 5 cross-faction combos: Full Pipeline, Deep Think, War Council, Iron Wall, Phoenix Rise
- 4 resource types: Crystals (commits/tasks), Shards (diary/decisions), Tokens (quests/streaks), Sparks (synergy/dreams)
- Quest system auto-generate 3 daily + 1 weekly + 1 epic + hidden quests berdasarkan game day
- Challenge events 3% chance per tick bila agents aktif — resolve berdasarkan squad stats
- Mentor system: Growth 4+ NPC auto-mentor Growth 0-2, +50% XP multiplier
- 7 unlockable buildings dengan gameplay effects (Training Grounds, Arena, Ascension Shrine, dll)
- Semua state persist ke localStorage
- Sungai ditolak Abam — hanya kapal terbang dikekalkan
